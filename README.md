# FastAPI App 1

Простое FastAPI-приложение для работы с отелями и бронированиями. Проект демонстрирует базовую структуру REST API на FastAPI с асинхронным доступом к базе данных через SQLAlchemy и поддержку миграций Alembic.

## Что умеет проект

- Получать список отелей с фильтрацией по городу, датам, звёздности и наличию SPA
- Просматривать информацию по конкретному отелю
- Получать список бронирований
- Получать бронирование по идентификатору
- Поддерживать подключение к PostgreSQL через переменные окружения

## Технологии

- FastAPI
- SQLAlchemy 2.x
- Alembic
- asyncpg
- Pydantic / Pydantic Settings
- Uvicorn

## Структура проекта

- main.py — точка входа приложения
- app/config.py — настройки приложения и загрузка переменных окружения
- app/database.py — настройка SQLAlchemy и асинхронного движка
- app/models/ — SQLAlchemy-модели
- app/routers/ — маршруты API
- app/schemas/ — Pydantic-схемы
- app/services/ — сервисный слой для работы с данными
- app/migrations/ — миграции Alembic

## Требования

- Python 3.12+
- PostgreSQL
- uv (рекомендуется) или pip

## Установка

1. Создайте виртуальное окружение и установите зависимости:

```bash
uv sync
```

2. Создайте файл .env в корне проекта со следующим содержимым:

```env
DB_HOST=localhost
DB_PORT=5432
DB_USER=postgres
DB_PASS=postgres
DB_NAME=fastapi_app1
```

## Запуск приложения

Запуск через uv:

```bash
uv run uvicorn main:app --reload
```

Или через Python:

```bash
python main.py
```

Приложение будет доступно по адресу:

- http://127.0.0.1:8000

## API

### Отели

- GET /hotels/ — список отелей
- GET /hotels/{hotel_id} — информация по отелю
- POST /hotels/bookings — создание бронирования (в текущей реализации — заготовка)

### Бронирования

- GET /bookings/ — список бронирований
- GET /bookings/{booking_id} — бронирование по идентификатору

## Миграции базы данных

Применение миграций:

```bash
alembic upgrade head
```
